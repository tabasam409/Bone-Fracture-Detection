# Bone Fracture Detection using Deep Learning

## Description
A medical AI project that detects bone fractures from X-ray images using Deep Learning. The CNN model is trained to classify X-ray images as fractured or non-fractured, aiding in medical diagnosis.

## Technologies
- Python
- TensorFlow / Keras
- OpenCV
- NumPy
- Matplotlib
- Jupyter Notebook

## Trained Model
The trained model (`bone_fracture_identifier.h5`) is included in this repository.

## How to Run
1. Clone the repository:
   ```bash
   git clone https://github.com/tabasam409/Bone-Fracture-Detection.git
   cd Bone-Fracture-Detection
   ```
2. Install dependencies:
   ```bash
   pip install tensorflow keras opencv-python numpy matplotlib
   ```
3. Open and run the Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

## Dataset
The model was trained using an X-ray image dataset organized in the `train/` directory. The dataset is not included in this repository.
